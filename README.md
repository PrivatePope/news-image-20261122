# The World in One Day — 22 November 2026

A newspaper front page summing up Sunday 22 November 2026: COP31's
near-final climate deal in Antalya, Australia's AUKUS defence, Pant's
century in Wellington, plus the weekend's other big stories.

Entry for the make.fun bounty [Sum up 22 November's world news in one
image](https://make.fun/bounty/news-image-20261122) — $100, 50 places.

## How it works

`main.py` (Python 3.13, standard library only) copies the bundled
`entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`).
The image itself was drawn with PIL; the repo ships the finished image.

## Run

```sh
python3 main.py
```
